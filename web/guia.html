Probalo en tu computadora

Probá el contrato Soroban con Rust y usá la demo para crear escrows y aportar USDC de Testnet mediante Trustless Work.

1. Abrí PowerShell en la raíz del proyecto

La carpeta debe contener Cargo.toml y README.md.

2. Ejecutá las pruebas

cargo test --locked --offline
stellar contract build --locked

Debe aparecer 6 passed; 0 failed. La compilación genera el archivo WASM en target/wasm32v1-none/release/.

3. Abrí la demo visual

npm install
npm run dev

En el navegador abrí 127.0.0.1:4173/web/. Si PowerShell no encuentra npm, ejecutá node server.mjs después de instalar las dependencias.

4. Creá y aportá en Trustless Work

Conectá tu wallet en Testnet, creá una mejenga y firmá. Cada fila muestra su propio saldo y meta en USDC. Para aportar necesitás USDC de prueba y XLM para la comisión. El número de jugadores cuenta las wallets que usaron esta demo local.

Abrir dashboard de Testnet ↗

5. Contrato de la tarea

El contrato Soroban propio se prueba con Rust y tiene reglas de meta, cupo y plazo en cadena. Está separado de los escrows USDC de Trustless Work que usa la interfaz.
